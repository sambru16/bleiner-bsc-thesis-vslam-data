# bleiner-bsc-thesis-vslam-data

This repository contains the raw data used for my bachelor’s thesis:

"Evaluation of Vision-Based Localization and Mapping Algorithms in Diverse Weather and Lighting Conditions"

## Content

- The raw experiment results are stored in the main result folders:
  - DM-VIO_Stereo
  - DM-VIO_Stereo_Inertial
  - ORBSLAM3_Stereo
  - ORBSLAM3_Stereo_Inertial
- The file VSLAM_Evaluation.csv contains the evaluated metrics for all runs.
- The folders contain the underlying run outputs and related files that were used to compute these metrics.
